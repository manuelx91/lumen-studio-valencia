# Lumen Studio — Trabajo HTML5 y CSS3

Sitio web ficticio de Lumen Studio, un estudio creativo digital situado en **Calle Padre Urbano, 46009 Valencia, España**.

## Contenido

- `index.html`: página de inicio.
- `views/productos.html`: galería de proyectos.
- `views/presupuesto.html`: formulario de presupuesto con validación HTML5.
- `views/contacto.html`: datos de contacto y mapa.
- `css/styles.css`: estilos responsive.
- `imagenes/mapa-valencia.png`: mapa raster de la ubicación de la empresa.
- `imagenes/producto-*.jpg`: fotografías de los trabajos de la galería.

## Direcciones de entrega

- **Repositorio de GitHub:** https://github.com/manuelx91/lumen-studio-valencia
- **Hosting en GitHub Pages:** https://manuelx91.github.io/lumen-studio-valencia/

> Estas direcciones corresponden al repositorio público previsto para la entrega. GitHub Pages debe activarse desde `Settings → Pages` usando la rama `main` y la carpeta `/ (root)`.

## Tecnologías

El proyecto utiliza únicamente **HTML5 y CSS3**, sin JavaScript ni frameworks.
